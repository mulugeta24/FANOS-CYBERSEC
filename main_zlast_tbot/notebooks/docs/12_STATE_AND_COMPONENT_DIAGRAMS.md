## Interface Specifications

### 1. Database Interface

```
<<interface>>
DatabaseInterface
─────────────────
+ init_db(): void
+ get_stat(key: str): int
+ increment_stat(key: str): void
+ get_cache(url: str): str
+ set_cache(url: str, result: str): void
+ add_report(...): int
+ get_reports(limit: int): list
+ get_report_stats(): dict
```

### 2. ML Detector Interface

```
<<interface>>
MLDetectorInterface
───────────────────
+ predict(url: str): str
+ predict_with_prob(url: str): tuple
+ extract_features(url: str): array
```

### 3. External API Interface

```
<<interface>>
ExternalAPIInterface
────────────────────
+ get_vt_report(url: str): str
+ parse_response(response: dict): str
+ handle_error(error: Exception): str
```
